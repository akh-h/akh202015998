# 2023년 산업연관표(투입산출표) 다층 분류 분석 웹앱

본 프로젝트는 한국은행의 2023년 연장 투입산출표(생산자가격 기준)를 활용하여 **통합대분류(33부문), 통합중분류(83부문), 통합소분류(165부문), 기본부문(380부문)** 데이터를 브라우저 환경(Pyodide + Web Worker)에서 직접 검증·탐색하고 다양한 경제적 파급효과를 시뮬레이션하는 정적 웹 애플리케이션입니다.

## 1. 지원 데이터 및 분류 체계 (`data/` 폴더)
- **통합대분류 (33개 부문)**: `./data/(표)(2023연장)투입산출표_생산자가격_통합대분류.xlsx`
- **통합중분류 (83개 부문)**: `./data/(표)(2023연장)투입산출표_생산자가격_통합중분류.xlsx`
- **통합소분류 (165개 부문)**: `./data/(표)(2023연장)투입산출표_생산자가격_통합소분류.xlsx`
- **기본부문 (380개 부문)**: `./data/io-2023.xlsx`
- 각 통합문서는 총거래표, 국산거래표, 수입거래표, 투입계수표(총·국산·수입), 유발계수표(생산·수입·부가가치), 최종수요 항목별 유발액 등 **총 12개 시트**로 구성되어 있습니다.

## 2. 웹앱 사용 방법
1. **분류 기준 선택 및 자료 불러오기**:
   - `1. 투입산출표 분류 선택 및 원자료 탐색` 영역 상단 드롭다운에서 **통합대분류(33), 통합중분류(83), 통합소분류(165), 기본부문(380)** 중 원하는 기준을 선택하고 **`선택한 분류 자료 불러오기`** 버튼을 클릭합니다.
   - 데이터 로딩 시 브라우저 내 Pyodide가 작동하며, 행렬 항등식 검증 결과를 상단 `계수 검증 결과` 영역에서 확인할 수 있습니다.
2. **원자료 시트 및 산업/항목 검색**:
   - **시트 구분 선택**에서 12개 시트 중 하나를 고르고, **행 검색**과 **열 검색** 입력창에 산업명(예: `반도체`, `자동차`, `농림`) 또는 코드(예: `C01`, `0111`, `9690`)를 입력하여 원하는 교차 데이터를 즉시 탐색합니다.
3. **최종수요 증가 시뮬레이션**:
   - `2. 국내 생산물 최종수요 증가 시뮬레이션` 영역에서 대상 산업을 검색·선택하고 최종수요 증가액(단위: **백만원**)을 입력한 뒤 **`시나리오에 추가`**를 누릅니다.
   - 단일 산업 또는 복수 산업의 복합 수요충격 시나리오를 구성한 후 **`파급효과 계산`**을 누르면 경제 전체의 총 생산유발액, 수입유발액, 부가가치유발액, 종합 생산유발배수 및 상위 15개 파급 산업 막대그래프가 산출됩니다. 결과는 CSV로 다운로드할 수 있습니다.
4. **산업별 유발계수 및 전·후방 연쇄효과 구조 분석**:
   - `3. 산업별 유발계수 및 전·후방 연쇄효과 구조 분석` 영역에서 각 산업의 생산·부가가치·수입유발계수 합계와 영향력계수(후방연쇄), 감응도계수(전방연쇄)를 정렬·검색하여 핵심 전략 산업 및 병목 산업을 판별합니다.

## 3. 적용된 산업연관분석 방법론 및 단위 체계

### (1) 계수 행렬 정합성 검증
- 국산투입계수 행렬 $A^d$, 수입투입계수 행렬 $A^m$, 부가가치계수 대각행렬 $\hat{v}$에 대하여 엑셀 원자료의 생산유발계수 $L = (I - A^d)^{-1}$, 수입유발계수 $M = A^m L$, 부가가치유발계수 $V = \hat{v} L$ 간의 최대 절대 잔차($\max |(I - A^d)L - I|$ 등)가 $10^{-8}$ 미만인지 자동 검증합니다.

### (2) 최종수요 충격 파급효과 모형
- 국내 생산물에 대한 최종수요 증가 벡터 $\Delta f$ (단위: **백만원**) 발생 시:
  - **생산유발액 (백만원)**: $\Delta x = (I - A^d)^{-1} \Delta f = L \Delta f$
  - **수입유발액 (백만원)**: $\Delta m = A^m (I - A^d)^{-1} \Delta f = M \Delta f$
  - **부가가치유발액 (백만원)**: $\Delta v = \hat{v} (I - A^d)^{-1} \Delta f = V \Delta f$
  - **종합 생산유발배수 (배)**: $\sum \Delta x_i / \sum \Delta f_i$

### (3) 전·후방 연쇄효과 분석 (영향력계수 및 감응도계수)
- 생산유발계수 행렬 $L = [l_{ij}]$ ($N$개 부문)을 가공하여 산업구조적 위치를 분석합니다.
  - **영향력계수 (후방연쇄효과, 상대지수)**: $BL_j = \frac{\sum_{i=1}^N l_{ij}}{\frac{1}{N}\sum_{i=1}^N \sum_{k=1}^N l_{ik}}$ (전 산업 평균 = $1.0$ 기준, 해당 산업의 최종수요 1단위 증가 시 전 산업에 미치는 상대적 생산 파급 크기)
  - **감응도계수 (전방연쇄효과, 상대지수)**: $FL_i = \frac{\sum_{j=1}^N l_{ij}}{\frac{1}{N}\sum_{k=1}^N \sum_{j=1}^N l_{kj}}$ (전 산업 평균 = $1.0$ 기준, 전 산업의 최종수요가 각각 1단위씩 증가할 때 해당 산업이 받는 상대적 수요 감지 크기)
  - 두 지수가 1.0 이상인지 여부에 따라 **중간재 제조업형(전·후방 모두 높음)**, **최종수요 제조업형(후방 높음)**, **원자재·기초투입형(전방 높음)**, **최종수요 서비스형(전·후방 모두 낮음)**으로 산업 유형을 자동 분류합니다.

### (4) 데이터 단위 명시 기준
- **거래표 및 유발액**: `백만원`
- **투입계수 및 유발계수**: `무단위 비율 (계수 / 배)`
- **영향력계수 및 감응도계수**: `상대지수 (전 산업 평균 = 1.0)`
- **구성비**: `% (백분율)`

## 4. 자료 공개 권한 및 보안 점검
- 본 저장소에 포함된 데이터는 한국은행 경제통계시스템(ECOS)에서 공표한 2023년 연장 투입산출표 공개 통계자료이며, 어떠한 개인정보, API 키, 비밀번호 등 민감 정보도 포함하지 않습니다.
